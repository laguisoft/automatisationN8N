# tests/e2e

Reserve pour des scenarios de bout en bout (ex : declenchement d'un run via
l'API, verification de la creation d'un prospect en base, validation via le
dashboard, generation du message) executes contre une stack Docker Compose
complete. Aucun scenario n'est fourni pour l'instant : voir
`tests/integration` pour les tests necessitant une base de donnees reelle.
