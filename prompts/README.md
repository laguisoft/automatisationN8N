# prompts

Bibliotheque des prompts utilises par les composants IA du projet
(recherche/qualification de leads, enrichissement, redaction de messages de
prospection, resume de donnees). Chaque prompt est versionne en tant que
fichier texte/markdown independant du code, afin de pouvoir etre modifie,
teste et revu sans toucher a l'application.

Convention suggeree : un sous-dossier par cas d'usage (ex :
`prompts/lead-scoring/`, `prompts/lead-enrichment/`, `prompts/outreach/`),
avec un fichier par version de prompt.
