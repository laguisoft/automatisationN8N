# docs

Documentation technique et fonctionnelle du projet.

- `installation.md` : installation locale et premiers pas.
- `docker-guide.md` : services Docker Compose, build, healthchecks.
- `n8n-guide.md` : credential a creer, role des workflows fournis, import/export.
- `environment-variables.md` : reference complete des variables `.env`.
- `apis-guide.md` : obtention des cles API et politiques d'usage par fournisseur.
- `workflows-guide.md` : detail du pipeline de prospection et ou vit chaque etape dans le code.
- `maintenance.md` : ajouter un moteur de recherche, un canal d'envoi, ajuster le scoring, migrations.
- `data-privacy.md` : securite, limitation de debit, robots.txt, validation humaine, consentement, protection des donnees.
